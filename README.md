# tz-1

Консольный скрипт на Python: делает 10 последовательных GET-запросов к заданному адресу
(например, к тяжёлой картинке), на каждый дожидается полного ответа и печатает среднее время
запроса, общий объём скачанных данных и скорость скачивания.



## Запуск

```bash
python main.py
```

## Пример вывода

```
Укажите URL-адрес: https://example.com/big.jpg

# 1     4.212 МБ    812.40 мс      5.18 МБ/с
# 2     4.212 МБ    790.11 мс      5.33 МБ/с
...

--- Итого ---
Успешных запросов:     10 из 10
Среднее время запроса: 801.25 мс
Общий объём:           42.120 МБ (44165120 байт)
Скорость скачивания:   5.26 МБ/с
```

## Единицы измерения

- Объём: **МБ**, где 1 МБ = 1 048 576 байт (1024 × 1024). Точное значение в байтах тоже выводится.
- Время: **миллисекунды (мс)**.
- Скорость: **МБ/с** (мегабайты в секунду, 1 МБ = 1 048 576 байт).
